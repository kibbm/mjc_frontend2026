개인 도서대장 — 65세 이상 사용자를 고려한 화면 개선

실행 방법
1. 압축 파일을 모두 풉니다.
2. index.html을 Chrome 또는 Edge로 엽니다. 인터넷 연결이나 설치는 필요 없습니다.
3. CSS를 수정하려면 senior.css를 편집한 뒤 브라우저를 새로 고칩니다.
   index.html / senior.css / book.jpg는 같은 폴더에 두세요.

단일 HTML 파일을 받은 경우
index(3).html에는 CSS와 책 이미지가 포함되어 있어 이 파일만 열어도 실행됩니다.
CSS를 직접 수정하려면 HTML의 <style> 영역을 편집하세요.

원본 파일 분석
- 원본 HTML: 자체 JavaScript로 등록·수정·삭제·검색·목록·페이지 이동을 처리하며,
  bookly-library-v1이라는 localStorage 키에 기록을 저장합니다.
- book.jpg: 180×150 크기의 책 이미지입니다. 원본 이미지를 그대로 사용했습니다.
- dbHandle.js: jQuery / jQuery Mobile과 Web SQL을 사용하는 별도의 코드입니다.
  첨부 HTML에서 불러오지 않는 코드이므로 현재 실행에는 연결하지 않았습니다.
  reference 폴더에는 제공된 원본 그대로 넣었습니다.

화면 변경
- 종이 도서대장과 도서관 안내문을 떠올리는 미색 배경, 짙은 초록, 명확한 선.
- 본문 20px / 보조 글씨 18px부터. ‘글자 더 크게’로 본문을 24px로 확대.
- 버튼 최소 높이 56px, 입력칸과 주 메뉴 최소 높이 60px.
- 영문 메뉴를 쉬운 한글로 변경하고, 메뉴 순서를 처음 화면·책 목록·등록·수정·삭제로 정리.
- 아이콘만 있던 수정·삭제 버튼에 글자 표시. 모바일에서도 메뉴 이름 유지.
- 검색 입력칸에 항상 보이는 이름표. 검색 결과 없음 안내와 전체 목록 복귀 버튼.
- 읽기 전에 사라지던 처리 결과를 화면 위에 계속 표시.
- 입력 지우기와 등록하기 구분, 삭제 전 제목 확인, 취소 버튼에 먼저 키보드 초점.
- 키보드 초점 표시, 본문 바로 가기, 화면 변경 시 제목으로 초점 이동.
- 글자 크기 설정과 기존 도서 저장 키/자료 구조 유지.
- 저장할 수 없을 때 완료 안내에 저장 실패 경고가 함께 표시되도록 보완.

저장 안내
기록은 같은 기기의 같은 브라우저에 저장됩니다. HTML 파일 경로나 브라우저가 바뀌면
이전 기록이 보이지 않을 수 있습니다. 브라우저 저장 데이터를 지우면 기록도 지워집니다.
HTML 파일 자체에는 사용자가 등록한 책 데이터가 저장되지 않습니다.
기존 기록을 계속 사용하려면 사용하던 HTML 경로를 유지하고 내용만 교체하세요.
기존 Web SQL 데이터와의 자동 연동/이전 기능은 포함하지 않았습니다.

검증
Chromium에서 file://로 직접 실행해 외부 네트워크 요청 없이 확인했습니다.
등록·검색·수정·삭제·중복 제목·검색 결과 없음·종류 필터·페이지 이동·새로고침 후 유지,
삭제 취소·Esc·확인 창 초점·글자 크기 유지·저장 실패 안내·제목의 HTML 문자 처리를 검증했습니다.
글자 확대 상태의 320 / 390 / 640 / 768 / 1440px 화면에서 가로 넘침과 버튼 크기를 점검했습니다.
실제 65세 이상 사용자를 대상으로 한 사용성 시험은 진행하지 않았습니다.


사용 프롬프트
위 파일을 분석해서, local기반의 html5기술로 css3을 수정하는데, 65세 이상이 편하게 사용할 수 있는 인터페이스로 바꿔. 단, 인터페이스의 스타일은 기존의 AI가 만드는 스타일을 따라하지 말 것.
