    경로를 입력하고 탑승하세요.

    출발지와 도착지 입력 → 경로 계산 → 자율주행 시작 순서로 실행합니다. 장소명은 목록에서 고르거나 정확히 입력합니다.

    운전석 HMD는 모니터에서 몰입형 운전석을 보여줍니다. 차량 추적에서는 차체와 주행 경로, 도시 전체에서는 지도 전체를 관찰합니다.

    가상 센서 → 판단 → 제어 패널에 신호 상태, 다음 회전, 목표 속도, 제동 여부가 표시됩니다. 센서 링은 시각 효과이며 실제 LiDAR 측정이 아닙니다.

    전방 장애물 추가를 누르면 계획 경로 위에 방호벽이 나타납니다. 차량이 정지한 뒤 장애물 제거를 누르면 다시 출발합니다.

    실제 HMD: WebXR 지원 기기/브라우저와 HTTPS 또는 신뢰 가능한 로컬 환경이 필요합니다. VR에서 출발/도착 행을 컨트롤러로 클릭하면 장소를 순환 선택하고, 경로 확정 · 출발로 운행합니다. HMD 진입 시 일시 정지 및 1×로 전환합니다.

    움직임이 불편하거나 멀미가 느껴지면 즉시 일시 정지하고 HMD를 벗으세요. 모든 장소·신호·센서 정보는 가상입니다. 실제 차량 제어에 사용할 수 없습니다.
