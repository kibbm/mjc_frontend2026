어디부터 살펴볼까요?

차량을 드래그해 회전하거나 부품 이름을 눌러 보세요. 외장 패널을 열면 좌석과 엔진룸을 직접 확인할 수 있습니다.

추천 순서: 외형 탐색 → 실내 공간 → 운전석 탑승 → 기계 구조

특정 제조사의 차량이 아닌 교육용 개념 모델입니다. 부품 형상·배치·분해 방향은 이해를 돕기 위해 단순화했습니다. 실제 정비나 안전 판단의 근거로 사용하지 마세요.

자동차 3D 탐험 안내

외형, 실내 공간, 기계 구조를 오가며 자동차를 관찰하는 교육용 체험입니다.

  1. 마우스 왼쪽 드래그: 회전 / 휠: 확대·축소 / 오른쪽 드래그: 화면 이동
  2. 휴대전화: 한 손가락으로 회전, 두 손가락으로 확대·이동
  3. 운전석에서는 드래그로 고개를 돌립니다. Esc 또는 하차 버튼으로 나옵니다.
  4. 투명도·분해·단면을 조합하면 내부 구조를 확인하기 쉽습니다.
  5. 단축키: 1 외형 / 2 실내 / 3 기계 / D 문 / H 보닛 / R 초기화

Three.js r180을 CDN에서 불러오므로 인터넷 연결이 필요합니다. 앱 내 파일 미리보기에서 실행되지 않으면 데스크톱 웹브라우저 또는 로컬 웹 서버로 열어 주세요.
