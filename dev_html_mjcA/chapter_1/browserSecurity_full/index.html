브라우저는 나를 얼마나 알고 있을까?

JavaScript와 Browser API를 이용해 브라우저가 확인할 수 있는 정보와 권한이 필요한 정보를 직접 살펴봅니다.

STEP 1

권한 없이 확인 가능한 정보

버튼을 누르면 브라우저가 제공하는 환경 정보가 나타납니다.

STEP 2

미디어 장치 확인

카메라, 마이크, 오디오 출력 장치를 확인합니다. 권한이 없으면 장치 이름이 숨겨질 수 있습니다.

아직 장치를 확인하지 않았습니다.
STEP 3

권한 요청하기

브라우저가 권한 창을 보여줍니다. 이 프로젝트는 권한 확인 직후 오디오 스트림을 바로 종료합니다.

아직 권한을 요청하지 않았습니다.
STEP 4

Web Bluetooth 체험

지원되는 브라우저에서 사용자가 직접 장치를 선택해야 합니다. 웹페이지가 PC의 모든 Bluetooth 장치 목록을 마음대로 읽는 기능은 아닙니다.

아직 Bluetooth 장치를 선택하지 않았습니다.
STEP 5

웹사이트가 저장할 수 있는 형태로 보기

이 예제는 서버로 정보를 전송하지 않습니다. 현재 페이지에서 수집한 값만 JSON 형태로 보여줍니다.
