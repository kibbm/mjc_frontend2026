브라우저는 나를 얼마나 알고 있을까?

창 너비를 읽을 때와 마이크를 켤 때, 브라우저의 반응은 어떻게 다를까요? 버튼을 누르기 전에 결과를 예측하고, 화면에 나타난 차이를 설명해 봅시다.

준비Ver.1Ver.2Ver.3

실습 준비

  1. ZIP의 압축을 모두 풀고 VS Code에서 START_HERE.html이 들어 있는 폴더를 엽니다. 이 교안은 브라우저에서 읽습니다.
  2. VS Code의 Live Server가 있으면 START_HERE.html을 우클릭해 Open with Live Server를 선택하세요. Python이 있으면 같은 폴더에서 터미널에 python -m http.server 8000 --bind 127.0.0.1을 입력하고 http://localhost:8000/START_HERE.html을 여세요. Windows에서는 python 대신 py도 사용할 수 있습니다.
  3. 각 단계에서 start/ver번호/script.js를 열고 마지막 주석 아래에 코드를 한 번 붙여 넣습니다. Ctrl+S로 저장한 후 ‘내 실습 화면’을 열거나 새로고침하세요. complete 폴더에는 비교할 완성본이 있습니다.

HTML은 버튼과 결과 칸을 만들고, CSS는 모양을 정합니다. JavaScript는 버튼의 id를 찾아 동작을 연결합니다. 각 시작 폴더에는 이번 단계의 HTML·CSS와 직전 단계까지의 JavaScript가 들어 있습니다.

Ver.1　버튼으로 내 브라우저 읽기

개념

이벤트는 사용자의 행동을 코드에 연결합니다. #basicInfoBtn은 버튼의 id를 찾는 선택자입니다. click이 발생하면 showBasicInfo가 그 순간의 창 크기 등을 읽고 textContent로 결과 칸에 씁니다.

코드 붙여 넣기

start/ver1/script.js 마지막 줄 아래에 붙여 넣고 저장하세요.

// 버튼을 누른 시점의 값을 읽습니다.
const select = selector => document.querySelector(selector);
const observed = {};

function showBasicInfo() {
  observed.basic = {
    언어: navigator.language,
    시간대: Intl.DateTimeFormat().resolvedOptions().timeZone,
    화면: screen.width + " × " + screen.height,
    창: window.innerWidth + " × " + window.innerHeight
  };
  select("#basicInfo").textContent = Object.entries(observed.basic)
    .map(([name, value]) => name + " · " + value)
    .join("\n");
}

select("#basicInfoBtn").addEventListener("click", showBasicInfo);

실행 확인

① 내 정보 확인을 누르고 ‘화면’과 ‘창’을 비교하세요. ② 창 폭을 줄인 뒤 버튼을 다시 누르세요. 같은 모니터에서 어느 값이 바뀌었나요? ③ 코드의 ‘창’ 키를 ‘현재 창’으로 고쳐 저장·새로고침하고 다시 눌러 보세요.

이 코드는 클릭할 때만 값을 읽습니다. 창을 줄인 뒤 버튼을 다시 누르면 현재 너비를 읽습니다.

Ver.2　장치 목록과 마이크 권한 비교하기

개념

enumerateDevices()는 현재 페이지에 공개된 장치 목록을 돌려줍니다. getUserMedia()는 마이크 사용을 요청합니다. await는 결과를 기다리고, catch는 거절·장치 없음 등의 실패를 처리합니다. 허용 시 track.stop()으로 사용을 끝냅니다.

코드 붙여 넣기

start/ver2/script.js 마지막 줄 아래에 붙여 넣고 저장하세요.

// 목록 조회와 마이크 사용 요청은 서로 다른 동작입니다.
async function showDevices() {
  const output = select("#deviceList");
  if (!navigator.mediaDevices?.enumerateDevices) {
    observed.devices = null;
    output.textContent = "목록 조회를 지원하지 않습니다. 실행 주소를 확인하세요.";
    return;
  }
  try {
    const devices = await navigator.mediaDevices.enumerateDevices();
    observed.devices = devices.map(device => ({
      종류: device.kind,
      이름: device.label || "이름 비공개"
    }));
    output.textContent = observed.devices
      .map(device => device.종류 + " · " + device.이름)
      .join("\n") || "표시 가능한 장치가 없습니다.";
  } catch (error) {
    observed.devices = null;
    output.textContent = "목록 확인 실패 · " + error.name;
  }
}

async function checkMic() {
  const output = select("#permissionResult");
  if (!navigator.mediaDevices?.getUserMedia) {
    observed.micResult = "사용 불가";
  } else {
    try {
      output.textContent = "마이크 요청 결과를 기다리는 중입니다.";
      const stream = await navigator.mediaDevices.getUserMedia({ audio: true });
      stream.getTracks().forEach(track => track.stop());
      observed.micResult = "허용됨 · 스트림 종료";
    } catch (error) {
      observed.micResult = "요청 실패 · " + error.name;
    }
  }
  output.textContent = observed.micResult;
  await showDevices();
}

select("#deviceBtn").addEventListener("click", showDevices);
select("#micBtn").addEventListener("click", checkMic);

내 실습 화면 열기　·　완성본 비교

실행 확인

① 장치 목록 보기를 누르세요. 목록이 비거나 이름이 비공개일 수 있습니다. ② 마이크 권한 요청을 누르고 허용 또는 차단을 선택하세요. ③ 요청 결과와 다시 조회된 목록을 비교하세요. 이전에 권한을 결정했다면 창이 다시 뜨지 않을 수 있습니다.

장치 목록이 비었으면 컴퓨터에 마이크가 없다는 뜻일까요?

목록에는 브라우저가 이 페이지에 공개한 장치만 나타납니다. 장치 연결 상태, 권한, 실행 환경을 함께 살펴봐야 합니다.

Ver.3　장치 선택 결과를 JSON으로 보기

개념

requestDevice()는 사용자가 장치를 고르는 단계입니다. 선택된 이름이나 취소 결과를 observed 객체에 기록합니다. JSON.stringify()는 현재 객체를 문자열로 바꿉니다. 이 예제는 그 문자열을 화면에만 표시합니다.

코드 붙여 넣기

start/ver3/script.js 마지막 줄 아래에 붙여 넣고 저장하세요.

// 사용자가 고른 장치 이름만 표시합니다.
async function chooseDevice() {
  if (!navigator.bluetooth?.requestDevice) {
    observed.bluetooth = "이 환경에서 사용 불가";
  } else {
    try {
      const device = await navigator.bluetooth.requestDevice({
        acceptAllDevices: true
      });
      observed.bluetooth = device.name || "이름 없는 장치 선택";
    } catch (error) {
      observed.bluetooth = error.name === "NotFoundError"
        ? "선택된 장치 없음"
        : "선택 실패 · " + error.name;
    }
  }
  select("#bluetoothResult").textContent = observed.bluetooth;
}

function showJson() {
  select("#jsonResult").textContent = JSON.stringify(observed, null, 2);
}

select("#bluetoothBtn").addEventListener("click", chooseDevice);
select("#jsonBtn").addEventListener("click", showJson);

내 실습 화면 열기　·　완성본 비교

실행 확인

① 새로고침 직후 JSON 보기를 눌러 {}를 확인하세요. ② 내 정보 확인 → JSON 보기를 눌러 basic이 추가됐는지 보세요. ③ Bluetooth 장치 선택 창을 취소하거나 본인 장치를 선택한 뒤 JSON 보기를 다시 누르세요. 미지원 환경에서도 상태 문구를 비교할 수 있습니다.

JSON에 보인 값은 새로고침 후에도 남을까요?

observed는 현재 페이지 메모리에만 있습니다. 새로고침 후 JSON 보기를 누르면 다시 {}입니다. 현재 값으로 다시 그리려면 JSON 보기 버튼을 누릅니다.

버튼을 눌러도 반응이 없다면

편집한 파일과 브라우저 주소의 ver 번호가 같은지 확인하세요. 저장 후 새로고침하고 F12 → Console을 보세요. 이미 선언했다는 오류가 뜨면 같은 코드를 두 번 붙였는지 확인하세요. 장치 API가 사용 불가라면 localhost 또는 HTTPS 주소에서 다시 실행하세요. NotAllowedError는 권한·정책 제한, NotFoundError는 마이크 요청에서 적합한 장치를 찾지 못한 경우에 나타날 수 있습니다.
