02접이식 아코디언

jQuery Mobile 1.0 기본 위젯: data-role="collapsible-set"

HTML5란?

웹 문서의 제목, 문단, 입력 폼, 표 등 구조를 표현하는 표준 마크업 언어입니다.

CSS3란?

색상, 배치, 크기, 화면에 따른 반응형 스타일을 정의합니다.

jQuery Mobile이란?

모바일 화면에 맞는 터치 친화적인 UI를 제공하는 오래된 JavaScript UI 프레임워크입니다.
