UNIT 01

라디오 버튼과 체크박스

단일 선택과 다중 선택을 처리한다.

라디오 버튼(Radio)은 여러 선택지 중 정확히 하나를 선택할 때 사용한다. 같은 그룹에 속하는 라디오 버튼은 동일한 name을 지정한다. 체크박스(Checkbox)는 여러 항목을 동시에 선택할 때 사용한다.

예제 코드

<fieldset data-role="controlgroup">
  <legend>수강 방법 선택</legend>
  <input type="radio" name="course" id="online" value="온라인" checked>
  <label for="online">온라인</label>
  <input type="radio" name="course" id="offline" value="오프라인">
  <label for="offline">오프라인</label>
</fieldset>
<fieldset data-role="controlgroup">
  <legend>관심 분야 (복수 선택)</legend>
  <input type="checkbox" id="ai" value="인공지능">
  <label for="ai">인공지능</label>
  <input type="checkbox" id="web" value="웹 개발">
  <label for="web">웹 개발</label>
</fieldset>

실습 방법 및 결과

수강 방법에서는 하나만 선택되는지 확인하고, 관심 분야에서는 두 항목을 동시에 선택해 본다. label for는 해당 input id와 연결해야 한다.

버전 확인: jQuery Mobile 1.0 기본 제공
UNIT 02

셀렉트 메뉴 (Select Menu)

드롭다운 목록에서 항목을 선택한다.

select 안에 여러 option을 작성하고, 사용자가 하나를 선택하도록 한다. 화면 공간을 절약할 수 있어 지역·학과·옵션 선택 등에 적합하다.

예제 코드

<label for="major">학과 선택</label>
<select id="major">
  <option value="AI">인공지능학과</option>
  <option value="SW">소프트웨어학과</option>
  <option value="SEC">정보보호학과</option>
</select>
<script>
$(document).ready(function(){
  $("#major").bind("change",function(){
    $("#result").text("선택: " + $(this).val());
  });
});
</script>
<p id="result">선택 대기</p>

실습 방법 및 결과

목록에서 학과를 바꾼 후 선택 코드(AI/SW/SEC)가 출력되는지 확인한다. change는 값 변경 시 발생하는 이벤트이다.

버전 확인: jQuery Mobile 1.0 기본 제공
UNIT 03

플립 스위치 (Flip Switch)

두 상태(ON/OFF)를 직관적으로 변경한다.

플립 스위치는 ON/OFF, 허용/차단 등의 이진 상태를 변경하는 UI이다. jQuery Mobile 1.0에서는 두 개의 선택지만 가진 select 요소에 data-role="slider"를 부여한다.

예제 코드

<label for="notice">알림 설정</label>
<select id="notice" data-role="slider">
  <option value="off">OFF</option>
  <option value="on">ON</option>
</select>

실습 방법 및 결과

스위치를 ON과 OFF로 변경해 보면서 선택된 value가 달라지는지 확인한다.

버전 확인: jQuery Mobile 1.0 기본 제공
UNIT 04

숫자 슬라이더 (Slider)

정해진 범위 안에서 수치를 조절한다.

input type="range"는 슬라이드 손잡이의 위치에 따라 값을 정한다. min, max, step, value 속성으로 범위를 지정한다.

예제 코드

<label for="volume">볼륨 조절</label>
<input type="range" id="volume" min="0" max="100" value="50">
<p id="volumeView">50</p>
<script>
$(document).ready(function(){
  $("#volume").bind("change", function(){
    $("#volumeView").text($(this).val());
  });
});
</script>

실습 방법 및 결과

손잡이를 움직여 0, 50, 100 근처로 이동시키고 표시 숫자의 변화를 확인한다. 실제 서비스에서는 밝기·볼륨·수량에 활용한다.

버전 확인: jQuery Mobile 1.0 기본 제공
UNIT 05

텍스트와 검색 폼 (Text / Search)

문자열을 입력하거나 검색어를 받는다.

type="text"는 일반적인 문자 입력, type="search"는 검색에 적합한 입력 형태이다. placeholder는 입력 전에 보이는 안내 문구이며, 데이터는 .val()로 얻는다.

예제 코드

<label for="name">이름 입력</label>
<input type="text" id="name" placeholder="이름을 입력하세요">
<label for="keyword">검색어</label>
<input type="search" id="keyword" placeholder="검색어를 입력하세요">
<a href="#" id="check" data-role="button">확인</a>
<p id="print"></p>
<script>
$(document).ready(function(){
  $("#check").bind("click", function(e){
    e.preventDefault();
    $("#print").text($("#name").val()+" / "+$("#keyword").val());
  });
});
</script>

실습 방법 및 결과

이름과 검색어를 입력하고 확인 버튼을 클릭하여 두 값이 화면에 표시되는지 점검한다. 입력 결과를 HTML에 끼워 넣을 때는 .html() 대신 .text()를 활용한다.

버전 확인: jQuery Mobile 1.0 기본 제공
UNIT 06

슬라이드 패널 (Panel)

화면 옆에서 나타나는 내비게이션 메뉴를 만든다.

패널은 모바일 화면의 공간을 효율적으로 사용하기 위한 사이드 메뉴이다. 오른쪽으로 열거나 왼쪽으로 닫는 방식으로 자주 사용된다. data-role="panel"은 1.3 이후에서만 유효하므로 이 실습에서는 CSS와 jQuery를 사용한다.

예제 코드

<button id="openMenu">메뉴 열기</button>
<div id="menu"><button id="closeMenu">닫기</button><p>홈 / 강의 / 설정</p></div>
<style>
#menu { position:fixed; top:0; left:-260px; width:240px;
        height:100%; background:#d9ecff; z-index:1000; }
</style>
<script>
$(document).ready(function(){
  $("#openMenu").bind("click", function(){
    $("#menu").stop(true,true).animate({left:"0px"},300);
  });
  $("#closeMenu").bind("click", function(){
    $("#menu").stop(true,true).animate({left:"-260px"},300);
  });
});
</script>

실습 방법 및 결과

메뉴 열기 버튼을 누르면 화면 왼쪽에서 메뉴가 나오는지 확인하고, 닫기 버튼을 누르면 다시 숨겨지는지 확인한다.

버전 확인: jQuery Mobile 1.0 미지원 → CSS + jQuery animate()로 대체
UNIT 07

접이식 아코디언 (Collapsible)

제목 클릭으로 콘텐츠를 펼치고 접는다.

접이식 요소는 공간을 절약하고 긴 본문을 단계별로 표시하는 데 적합하다. data-role="collapsible"은 단일 접이식 블록을 만들며, 여러 블록을 data-role="collapsible-set"으로 묶으면 아코디언처럼 동작한다.

예제 코드

<div data-role="collapsible-set">
  <div data-role="collapsible" data-collapsed="false">
    <h3>HTML5</h3><p>문서 구조를 작성한다.</p>
  </div>
  <div data-role="collapsible">
    <h3>CSS3</h3><p>디자인을 작성한다.</p>
  </div>
  <div data-role="collapsible">
    <h3>JavaScript</h3><p>이벤트를 처리한다.</p>
  </div>
</div>

실습 방법 및 결과

HTML5 제목을 펼친 다음 CSS3를 클릭하여 앞 항목이 자동으로 접히는지 확인한다.

버전 확인: jQuery Mobile 1.0 기본 제공
UNIT 08

팝업 (Popup)

중요한 정보를 오버레이 형태로 보여준다.

팝업은 간단한 안내, 이미지 확대, 확인 메시지 등을 제공한다. data-role="popup" 위젯은 1.2부터 지원되며, 1.0에서는 CSS 위치 조정 및 jQuery fadeIn()과 fadeOut()으로 대체한다.

예제 코드

<a href="#" data-role="button" id="openPopup">알림 보기</a>
<div id="popup" role="dialog" style="display:none">
  <p>학습 알림 메시지</p>
  <a href="#" data-role="button" id="closePopup">닫기</a>
</div>
<style>
#popup { position:fixed; top:50%; left:50%;
  transform:translate(-50%,-50%); padding:24px;
  background:white; border:2px solid #aacddd; z-index:2000; }
</style>
<script>
$(document).ready(function(){
  $("#openPopup").bind("click",function(e){e.preventDefault();$("#popup").fadeIn();});
  $("#closePopup").bind("click",function(e){e.preventDefault();$("#popup").fadeOut();});
});
</script>

실습 방법 및 결과

알림 보기를 클릭하여 창이 중앙에 나타나는지 확인한다. 실무 구현에서는 오버레이, 배경 클릭 닫기, 키보드 닫기, 포커스 관리 등을 추가한다.

버전 확인: jQuery Mobile 1.0 미지원 → CSS + fadeIn/fadeOut 대체
UNIT 09

반응형 테이블 (Responsive Table)

가로 표를 작은 화면에 맞게 변환한다.

큰 화면에서는 일반적인 표를 사용하고, 작은 화면에서는 카드형 레이아웃으로 전환할 수 있다. data-role="table"은 1.3 이후 지원하므로 1.0 실습에서는 CSS 미디어 쿼리를 사용한다.

예제 코드

<table class="responsive"><thead>
<tr><th>이름</th><th>전공</th><th>점수</th></tr>
</thead><tbody>
<tr><td data-label="이름">김학생</td><td data-label="전공">AI</td><td data-label="점수">95</td></tr>
</tbody></table>
<style>
.responsive {width:100%;border-collapse:collapse;}
.responsive th,.responsive td {border:1px solid #ccd; padding:10px;}
@media(max-width:600px){
  .responsive,.responsive tbody,.responsive tr,.responsive td{display:block;width:100%;}
  .responsive thead{display:none;}
  .responsive td:before{content:attr(data-label) ": ";font-weight:bold;}
}
</style>

실습 방법 및 결과

브라우저 개발자 도구에서 모바일 화면으로 전환하고 열이 세로로 재배치되는지 확인한다.

버전 확인: jQuery Mobile 1.0 미지원 → CSS 미디어 쿼리 대체
UNIT 10

그리드 레이아웃 (Grid Layout)

화면을 2~5개의 균등한 가로 열로 나눈다.

jQuery Mobile 1.0은 ui-grid-a(2단), ui-grid-b(3단), ui-grid-c(4단), ui-grid-d(5단)를 제공한다. 내부에는 ui-block-a부터 순서대로 지정한다.

예제 코드

<!-- 2단 배치 -->
<div class="ui-grid-a">
  <div class="ui-block-a">메뉴 A</div>
  <div class="ui-block-b">메뉴 B</div>
</div>
<!-- 5단 배치 -->
<div class="ui-grid-d">
  <div class="ui-block-a">A</div>
  <div class="ui-block-b">B</div>
  <div class="ui-block-c">C</div>
  <div class="ui-block-d">D</div>
  <div class="ui-block-e">E</div>
</div>

실습 방법 및 결과

2단부터 5단까지 코드를 작성하고 각각의 블록이 균등한 가로 폭으로 배치되는지 확인한다. 폭이 작은 화면에서는 5단의 가독성이 떨어질 수 있으므로 필요한 경우 다른 배치로 전환한다.

버전 확인: jQuery Mobile 1.0 기본 제공

4. 종합 실습 · 학생 설정 모바일 웹앱

다음 순서로 UI 요소를 조합한다.

① 화면 구성

헤더, 본문, 푸터를 포함한 기본 페이지를 작성한다.

② 사용자 정보

버튼 클릭 시 선택값을 읽고 .text()로 화면에 출력한다.

⑤ 부가 화면

아코디언으로 설명을 접고, 패널·팝업을 직접 구현한다.

⑥ 반응형 정리

테이블을 모바일 크기에 따라 재배치하고 그리드를 활용한다.

5. 형성평가 및 정리

  1. 문제: 라디오 버튼의 단일 선택에 영향을 주는 HTML 속성은?
    정답: 동일한 name 속성
  2. 문제: 플립 스위치에 적용할 속성은?
    정답: data-role="slider"
  3. 문제: 아코디언을 만드는 컨테이너 속성은?
    정답: data-role="collapsible-set"
  4. 문제: 5단 그리드의 클래스명은?
    정답: ui-grid-d
  5. 문제: jQuery Mobile 1.0에서 Popup과 Panel을 바로 사용할 수 있는가?
    정답: 아니오. 1.0에서는 지원하지 않으므로 CSS와 jQuery를 활용해 직접 구현한다.

수업 정리

폼은 사용자 입력을 받고, UI 구성 요소는 입력과 정보를 화면에 배치한다. jQuery는 이벤트를 통해 동작을 연결하고, jQuery Mobile은 지원 버전의 위젯에 디자인 및 터치 인터페이스를 적용한다.
